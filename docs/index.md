# Arachne Ledger Wiki

Arachne Ledger tracks your Arachne fights, rewards, costs, and profit in Hypixel SkyBlock.

## Getting started

Install Fabric Loader, Fabric API, and the latest Arachne Ledger JAR for Minecraft 26.1.2. Put the JAR in your Minecraft `mods` folder, then press **O** or use `/arachne` in game.

## Main controls

- **O** or `/arachne`: open the dashboard.
- **HUD**: move, resize, or change the live overlay.
- **Prices**: set item, Crystal, and Calling values.
- **New Session**: start a new session without deleting lifetime totals.
- **Adjust**: add a missed drop, income, or expense.

## Useful commands

`/arachne view` changes the HUD layout. `/arachne hud on` and `/arachne hud off` toggle it. `/arachne price <ITEM_ID> <coins>` sets an item value, and `/arachne export` saves a CSV export.

For the latest download, visit [Modrinth](https://modrinth.com/arachne-profit-tracker) or [GitHub Releases](https://github.com/olliehope/arachne-ledger/releases).
