## About

Arachne Ledger is a **Hypixel SkyBlock Arachne profit tracker** for **Minecraft 26.1.2**, built with Fabric. Track loot, Crystal and Calling costs, Scavenger coins, and net profit while farming in Arachne's Sanctuary in Spider's Den.

Features include:

- session and lifetime earnings, coins per hour, and projected profit per hour;
- customizable profit graphs and Minimal, Classic, or Split HUD layouts;
- Bazaar instant-sell and sell-offer pricing, NPC prices, and salvage values;
- Tarantula Pet and Arachne Fang RNG drop alerts; and
- Arachne achievements, session recaps, personal records, and fight history.

## Recommended Setup

Required: **Minecraft 26.1.2, Fabric Loader, Fabric API, and Java 25**. Download the mod JAR and put it in your `mods` folder.

[Mod Menu](https://modrinth.com/mod/modmenu) adds a configuration shortcut. Press **O** or run `/arachne` for the dashboard; use `/arachne settings` for options.
