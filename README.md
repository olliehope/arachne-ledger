# Arachne Ledger

Arachne kills, loot, summon costs, and profit for **Hypixel SkyBlock · Minecraft 26.1.2 · Fabric**.

[Modrinth](https://modrinth.com/project/arachne-profit-tracker) · [Releases](https://github.com/olliehope/arachne-ledger/releases) · [Wiki](https://github.com/olliehope/arachne-ledger/wiki) · [Changelog](CHANGELOG.md)

Install Fabric Loader, Fabric API, and the mod JAR in your `mods` folder. Requires **Java 25**.

Press **O** or run `/arachne` for the dashboard. Use `/arachne settings` or Mod Menu for options. Choose Minimal, Classic, or Split HUD layouts and show only the stats you want.

Build with JDK 25: `./gradlew build` or `.\gradlew.bat build`. The installable JAR is in `build/libs`. Source packages separate client wiring, SkyBlock parsing, tracking, accounting, configuration, pricing, and UI.
